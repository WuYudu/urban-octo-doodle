# 在 PyCharm 里打开这个实验（3 个设置）

本目录是"有序抓取"实验的完整代码 + 结果 + 文档。

## 0. 先看这个：`ModuleNotFoundError: No module named 'PIL' / 'numpy' / 'pulp'`

PyCharm 打开项目时**自动新建了一个 `.venv/`**（Python 3.14），这个环境是空的，
所以一运行就报缺包。两种解法，任选一种：

**解法 A（已经替你做好）：用 PyCharm 自己建的那个 `.venv`，包已经装进去了**

依赖已装进 `13_实验_有序抓取QUBO\.venv`：numpy 2.5.4、pillow 13.0.0、pulp 4.2.0、
highspy 1.15.1、dimod 0.12.23、dwave-samplers 1.8.0。直接再点一次运行即可。
如果 PyCharm 仍提示缺包，说明它用的是别的解释器 —— 看解法 B。

**解法 B：把解释器换成 bundled python（推荐，数字与报告完全一致）**

```
C:\Users\Administrator\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe
```

设置路径：`File → Settings → Project → Python Interpreter → Add Interpreter → Add Local Interpreter
→ System Interpreter → 粘贴上面的路径`，然后把 `_libs` 标成 Sources Root（见第 2 节）。

> 两种解释器的差异：`.venv` 是 Python 3.14 + numpy 2.5.4；bundled 是 Python 3.12 + numpy 2.3.5。
> 算法与结果一致，**耗时数字会有几毫秒级差异**（报告里的表是 3.12 上跑的）。

## 1. 解释器要能 import numpy / pulp

PATH 上的 `python` 是干净的 3.12.10，**没有 numpy**。要么用第 0 节的解法 A（`.venv`，已装好），
要么用解法 B 的 bundled python。

## 2. 把 `_libs` 标成 Sources Root（仅解法 B 需要）

依赖（pulp / dimod / dwave-samplers / Pillow / numpy）在 `_libs/` 里。
右键 `_libs` 文件夹 → `Mark Directory as` → `Sources Root`。

（等价于命令行里的 `$env:PYTHONPATH = "<本目录>\_libs;<本目录>\src"`。）

## 3. Run Configuration 的工作目录必须是 `src`

`bench.py`、`plots.py` 用相对路径找 `../results` 和 `../figures`。如果工作目录是项目根，
结果会写到根目录下（能跑，但文件位置不对）。

设置路径：`Run → Edit Configurations → Working directory` 改成 `...\13_实验_有序抓取QUBO\src`。

## 跑什么

| 脚本 | 作用 | 大约耗时 |
|---|---|---|
| `_check_qubo.py` | 验证 QUBO 编码（穷举 + 不变量），应输出 `ALL OK` | 5 秒 |
| `solve.py` | 单个场景，四种解并排打印序列与耗时 | 1 秒 |
| `bench.py --seeds 3` | 39 个实例的规模扫描，写 `results/bench_both.csv` | 3 分钟 |
| `plots.py` | 四张图，写 `figures/` | 1–2 分钟（含预算曲线） |

`plots.py` 用纯 Pillow 画图，不依赖 matplotlib。
